# 📸 Modern Photography Studio Portfolio

A minimalist, high-performance, and Awwwards-inspired portfolio and booking web application designed for a professional photographer based in Kandy, Sri Lanka. Built with modern web technologies to showcase visual heirlooms, infant milestones, couple portraiture, and cinematic moments.

## ✨ Features & Sections

- **Immersive Hero Section:** High-impact typography with fluid animations and direct call-to-actions.
- **Interactive Portfolio / All Albums:** Filterable image galleries designed with a dark-mode luxury aesthetic.
- **Services & Pricing Packages:** Clear breakdowns of couple shoots, birthday coverages, and infant/baby photography.
- **Behind The Lens & Equipment:** Showcases professional full-frame camera gear, safety measures, and infant-safe soft lighting.
- **Frequently Asked Questions (FAQ):** Smooth, expandable accordion components addressing travel, delivery timelines, and bookings.
- **Interactive Footer:** Integrated with instant WhatsApp booking links, social media handles, and active session status.
- **Smooth Animations:** Powered by **Framer Motion** for butter-smooth scroll reveals and micro-interactions.

---

## 🛠️ Tech Stack

- **Frontend Library:** React.js (Vite)
- **Styling:** Tailwind CSS (v4)
- **Animations:** Framer Motion
- **Icons:** React Icons (`react-icons`)
- **Deployment:** Vercel

## 🚀 Getting Started

To run this project locally on your machine, follow these simple steps:

### Prerequisites
Make sure you have **Node.js** installed on your system.

### Installation

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/lakshan-beast/photography-portfolio.git](https://github.com/lakshan-beast/photography-portfolio.git);

2. Navigate to the project directory:

    Bash
    cd photography-portfolio

3. Install dependencies:

    Bash
    npm install

4. Run the development server:

    Bash
    npm run dev

5. Open your browser and visit http://localhost:5173 to see the live site.
